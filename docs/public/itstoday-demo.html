WKAppBot Skill Harness -- Demo

A knowledge-compounding harness that lets a cheap model perform like an expensive one, and a fleet of parallel cheap models (Haiku, mini, Flash) out-cover a single premium one, by connecting each to a team own accumulated operational knowledge. Submitted for the Its Today Media AI Challenge.

Live skill browser GitHub repo

How the knowledge stays current

Every model in the fleet carries its own reflexes -- house rules loaded at session start. When any model makes a mistake, the fix gets written back into a skill immediately, in the same session, not filed away for later. The next session -- any model, any tier -- reconnects to that reflex automatically. Knowledge does not go stale between sessions: it updates itself the moment something breaks.
