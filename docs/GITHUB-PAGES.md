# GitHub Pages Setup

## Enable Pages

Repository settings:

- Pages
- Build and deployment
- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

## Result

GitHub Pages will host:

- `index.html`
- `chatgpt-wkappbot-dashboard.html`
