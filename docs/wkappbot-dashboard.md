# WKAppBot Dashboard

Static dashboard page:

- `chatgpt-wkappbot-dashboard.html`

Use it to:

- prepare an ephemeral relay launch payload
- connect to a running temporary relay
- check `/health`
- check `/metrics`
- watch `/events`

For secure workflow dispatch, use the Cloudflare Worker trigger sample:

- `connectors/chatgpt-wkappbot/cloudflare-worker-trigger.js`
