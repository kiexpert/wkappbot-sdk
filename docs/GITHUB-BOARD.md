# GitHub Board Pattern

GitHub Issues can be used as a lightweight board system.

## Mapping

- issue = post/thread
- issue comment = reply
- label = category
- reaction = vote
- workflow = automation
- GitHub Pages = frontend UI

## Example

Daily board issue:

- issue #21

## Possible Extensions

- render issues from GitHub API
- realtime comment polling
- Worker-backed posting API
- AI summaries
- daily digest generation
