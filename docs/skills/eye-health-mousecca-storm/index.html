Eye health degradation: MouseCCA analyze-hack spawn storm fix

Eye health drops to ~34% when MouseCCA analyze-hack server returns non-JSON (U prefix = Unhandled exception or Unauthorized). Eye respawns server every 300ms creating hundreds of zombie wkappbot-core processes. Fix: WKAPPBOT_EYE_MOUSECCA=0 env var disables worker. Code fix (2026-05-05): CAS guard + exponential backoff + auto-disable after 10 failures.

Steps

  1. [SYMPTOM] Eye health 34% or lower. tasklist shows 100+ wkappbot-core processes. Eye log (logs/eye.pid=CURRENT.log) shows repeated [MOUSE-CCA] Server error: U is an invalid start of a value at 300ms intervals followed by [MOUSE-CCA] analyze-hack server started (PID=...).
  2. [SPAWN CHAIN] wkappbot-core [Eye] -> StartMouseCcaWorker() -> spawns 'wkappbot-core analyze-hack --server' child -> server returns non-JSON (Unauthorized/Unhandled exception text) -> Eye catches JsonException -> kills server -> respawns after 300ms -> repeat indefinitely. Example: Eye PID=30940 spawned 135 zombie children in ~10 min (2026-05-05). Storm creator is always the Eye itself, not an external process.
  3. [ROOT CAUSE] AppBotEyeHoverAnalyzer.cs::StartMouseCcaWorker had no single-instance guard, no backoff, and no failure cap. Any non-JSON response triggered an infinite 300ms respawn loop.
  4. [CODE FIX - 2026-05-05] AppBotEyeHoverAnalyzer.cs now has: (1) Interlocked.CompareExchange CAS gate — only one spawn allowed at a time; (2) exponential backoff: 300ms->600->1200->2400->...->30000ms cap on consecutive failures; (3) auto-disable after 10 consecutive failures, loop downshifts to 5s polling. Recovery: set WKAPPBOT_EYE_MOUSECCA=1 or restart Eye.
  5. [EMERGENCY STOP] When storm is active: $eyePid = [regex]::Match((Get-ChildItem logs/eye.pid=*.log | Sort LastWriteTime -Desc | Select -First 1).Name,'eye\.pid=(\d+)').Groups[1].Value; Get-Process wkappbot-core | Where-Object Id -ne $eyePid | Stop-Process -Force; [System.Environment]::SetEnvironmentVariable('WKAPPBOT_EYE_MOUSECCA','0','User')
  6. [ZOMBIE CLEANUP] Kill all wkappbot-core except current Eye PID. May need 3-5 passes until count stabilizes. Then hot-swap Eye to load the code fix.
  7. [LOG BLOAT] Storm creates thousands of eye.pid=*.log files. Clean: Get-ChildItem logs/eye.pid=*.log | Sort LastWriteTime -Desc | Select-Object -Skip 10 | Remove-Item -Force
  8. [RE-ENABLE] When analyze-hack server is fixed: [System.Environment]::SetEnvironmentVariable('WKAPPBOT_EYE_MOUSECCA',$null,'User') or set to '1'. Then hot-swap Eye.
