wkappbot windows -- focus flag and no-filter relevance mode

Two new windows command modes: (1) --focus shows focused child hwnd + proper grap expression per window. (2) no-filter mode shows only wkappbot-related windows ranked by coverage score.

user/developer
windowsfocusgrapcoveragescoringrelevancea11yhwnd

Steps

  1. [FOCUS-FLAG] wkappbot windows [filter] --focus: for each window shows (a) KB focus child hwnd+class via GetGUIThreadInfo, (b) UIA leaf ControlType+position+editable, (c) proper paste-ready grap: {hwnd,pid,proc,cls}#AbsTagPath built via *** -- same format as a11y find output. Use when you need the grap for the currently focused element without running a11y find.
  2. [NO-FILTER-MODE] wkappbot windows (no args): instead of listing all windows, shows only wkappbot-related windows ranked by coverage score. Pass 1 (fast): proc-cov*3 + title-cov*2 + class-cov*1. Pass 2 (batch WMI, only for score==0 windows): cmdline-cov*2 via single SELECT ProcessId,CommandLine FROM Win32_Process WHERE ProcessId IN (...) query. Sort: score desc, foreground tiebreak. Symbols: wkappbot/wkappbot-core/a11y/WK AppBot/WhisperRing.
  3. [COVERAGE-FORMULA] coverage(field, sym) = matched_length / field_length (0..1). Plain string: matched_length = sym.Length. Regex (regex: prefix): matched_length = Regex.Match(field, pattern).Length -- NOT pattern length (avoids wrong coverage for OR-regex like regex:a
  4. bb). Exact match -> 1.0 (100%). Partial -> proportional. Source: InspectionCommands.Windows.cs Coverage() local function.
