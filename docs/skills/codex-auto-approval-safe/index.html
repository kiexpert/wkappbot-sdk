Codex Auto Approval Safe

Reduce repeated Codex approval prompts by backing up and extending .codex rules with narrow allow-prefix patterns.

user/developer
codexapprovalrulesautomationsafety

Steps

  1. Inspect .codex config and rules before changing anything.
  2. Treat Codex approval_policy as host-controlled unless a documented local config key is confirmed; do not claim full global disable unless verified.
  3. Back up default.rules before editing it.
  4. Add only narrow prefix_rule allow patterns for repetitive trusted commands such as wkappbot, repo-local tools scripts, pip --user installs, Invoke-WebRequest, and winget search/install.
  5. Do not add broad arbitrary-script approvals such as plain python, powershell, cmd, or destructive file operations.
  6. Record what was added, when it was added, and the backup path so the rules can be reviewed or rolled back later.
  7. Maintainer sync (2026-05-01): HQ copy is authoritative.
