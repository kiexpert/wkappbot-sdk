User Skill Template

Template for skills that explain product actions to end users without exposing internal implementation details.

user
skilltemplateuserproductguideworkflowhelp

Steps

  1. Classify the skill as user-facing before writing anything else.
  2. Describe the product action in user language: click, search, send, review, export, or complete a task.
  3. Avoid implementation details unless they are needed for safety or to prevent user error.
  4. Keep the steps short and outcome-oriented; include a success criterion the user can see.
  5. If the skill depends on a project-specific rule, reference the project skill instead of copying internals here.
  6. If the skill starts to describe tooling or code behavior, split that part into a developer or operator skill.
