Ask Health Check (wkask)

End-to-end CDP ask pipeline health check via wkask.ps1. Run after hot-swap, Chrome accumulation, or before triad sessions.

Steps

  1. Run: powershell -File D:/GitHub/WKAppBot/bin/wkask.ps1 gpt 'say: PONG' -Timeout 60. Pass = PONG received in colour stream. Fail = timeout or Chrome stuck.
  2. Run: powershell -File D:/GitHub/WKAppBot/bin/wkask.ps1 gemini 'say: PONG' -Timeout 90. Common failure: off-screen Chrome -- check cdp-mon.ps1 for CRIT position drift.
  3. Run: powershell -File D:/GitHub/WKAppBot/bin/wkask.ps1 triad 'say: PONG' -Timeout 120. GPT+Gemini+Claude all must respond.
  4. On failure: powershell -File D:/GitHub/WKAppBot/bin/cdp-mon.ps1 -- look for CRIT flags (off-screen TGT-POS, LAT=DEAD, >5 sessions). Kill stale Chrome PIDs then retry.
  5. Stale session cleanup: Stop-Process -Id PID -Force for each stale PID shown by cdp-mon. Retry wkask after cleanup.
  6. Chrome restart loop (Runtime.enable timeout in log): wkappbot --sudo eye restart to force hot-swap and fresh Chrome session.
  7. Success baseline: gpt<60s, gemini<90s, triad<120s. Consistent timeouts = Chrome or network issue, not wkappbot code.
  8. When to run: after hot-swap deploy, after Chrome accumulation (cdp-mon shows >5), after network change, before triad sessions.
