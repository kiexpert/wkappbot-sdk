wkwrap: AI-native .sh/.cmd wrapper auto-install

Universal relay pattern for all wk*.ps1 tools. .sh for bash/Claude, .cmd for CMD/user, .ps1 for direct PS. wkwrap.sh --install auto-generates missing wrappers from wk*.ps1 scan.

user/developer

Steps

  1. PATTERN: each wkXXX.ps1 in WKAppBot/bin gets .sh (bash relay) + .cmd (CMD relay) counterparts auto-managed by wkwrap.sh/cmd.
  2. RELAY: wkXXX.sh -> powershell -File wkXXX.ps1 via wkwrap.sh. wkXXX.cmd -> same via wkwrap.cmd. basename $0 detection.
  3. INSTALL: wkwrap.sh --install scans wk*.ps1, creates missing .sh + .cmd. Run after adding new .ps1 tools.
  4. STATUS: wkwrap.sh --status shows coverage table (.ps1 / .sh / .cmd per tool).
  5. HARNESS GUIDANCE (MANDATORY): always refer users to .sh (bash) or .cmd (CMD) -- never .ps1 in harness error messages. PS1 is for direct expert use only.
  6. MAINTENANCE: wkharness -Status calls wkwrap.sh --install automatically to keep wrappers up to date.
  7. SPECIAL WRAPPERS (not relay): wkclaude.sh pre-bakes --print --model haiku. wkcodex.sh calls wkcodex.ps1 (harness symlink). These are NOT replaced by --install.
