Build a Claude Agent Team — No SDK, No Coding (WKAppBot Way)

Create a multi-agent analysis team (orchestrator + sub-agents) using only Claude chat. Anthropic official format: YAML frontmatter + markdown system prompt. In WKAppBot: skills/ replace MD files, ask triad replaces parallel Codebase execution, Eye handles scheduling.

Steps

  1. OVERVIEW: No SDK or coding needed. Describe the agent team in Claude chat and ask it to follow the Anthropic official agent guide format. Claude generates ready-to-deploy markdown files -- in WKAppBot these become skill files in skills/.
  2. FORMAT: Each agent = one markdown (.md) file with YAML frontmatter (name, description, tools, model) + system prompt body. In WKAppBot: use wkappbot skill contribute to register each sub-agent as a skill with its role, rules, and output format.
  3. KEY FLAG: Add 'proactively_uses: true' in the description field -- Claude auto-invokes appropriate sub-agents without explicit instruction. WKAppBot equivalent: skill audience=operator makes skills auto-loaded into Claude context; Claude picks relevant ones without being told.
  4. ORCHESTRATOR PATTERN: One lead agent (orchestrator) + N sub-agents each owning one domain (company overview, financials, industry trend, risk). WKAppBot: CLAUDE.md is the orchestrator; each skill is a sub-agent persona. One skill per domain, not one giant prompt.
  5. PARALLEL EXECUTION: wkappbot ask triad runs GPT + Gemini + Claude simultaneously on the same question -- each AI is a sub-agent. Results debate in Slack thread, then synthesize. Far faster than sequential single-AI loop.
  6. DEPLOY: No folder setup or zip needed. wkappbot skill contribute registers the agent. wkappbot skill read <id> loads its context. Claude reads relevant skills automatically at session start via CLAUDE.md skill index.
  7. PROMPT EXAMPLE (stock analysis): 'wkappbot ask triad "Defense stocks surging on Iran conflict. Analyze top 3 Korean + top 3 US defense stocks: fundamentals, valuation, risk. Output: ranked buy recommendation."' -- triad = three analysts in parallel.
  8. SCHEDULE: wkappbot schedule + Eye daemon. Example: every Monday 08:30 KST, Eye triggers 'wkappbot ask triad "Weekly defense stock scan: ...'" and posts result to Slack. No desktop app needs to stay open -- Eye runs as background service.
  9. EDIT/TUNE: To refine a sub-agent, wkappbot skill edit <id> --desc or --add-step. No file download, no zip, no folder juggling. Version auto-bumped on every edit.
