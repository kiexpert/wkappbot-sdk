wkappbot-core ★★★

통합 알림 디스패처 + 파일 기반 스케줄러

Single WkNotify() entry point routes to Slack/Prompt/Speak/Callout/Signal. Deferred/recurring prompts stored in {cwd}/.wkappbot/pending_prompts/ as filename-encoded schedules. Zero memory overhead -- file IS the schedule.

Steps

  1. CHANNELS: WkChannel.Slack, Prompt, Speak, Callout, Signal. Entry: WkNotify(n). Builders: WkNotification.ToSlack/ToPrompt/ToBoth/ToSpeak/Signal + .Deferred(DateTime) + .Recurring(TimeSpan).
  2. ROUTING: RunningInEye=true → fast-path direct (EyeMcpClient/SlackSendViaApi). RunningInEye=false → slack_queue/notify_*.json file-queue (drain within ~1s). Prompt+DeliverAfter → pending_prompts/ (not shared queue).
  3. FILENAME SCHEMA: prompt_{triggerUtc
  4. NOW}_{guid8}[,rep=Nh
  5. Nm
  6. Ns][,cnt=N].json in {cwd}/.wkappbot/pending_prompts/. Examples: prompt_NOW_abc.json (session-miss), prompt_20260429090000_def,rep=24h,cnt=5.json (daily x5).
  7. LIFECYCLE: rename on each delivery (update trigger, decrement cnt). cnt=0 → delete. rep without cnt → infinite. File IS the schedule -- Eye holds nothing in memory.
  8. DRAIN TRIGGERS: (1) any wkappbot command from that CWD via OnCommandArrived, (2) Eye startup AuditOnStartup(), (3) successful prompt delivery auto-drains pending for same CWD.
  9. SESSION-MISS: no target session → re-append with exponential backoff (30s→300s). No retry limit, no Slack escalation. Waits silently until session appears.
  10. TIME GATE: filename lexicographic filter -- NOW always passes; yyyyMMddHHmmss passes when <= current time. No JSON parse needed for gate check.
  11. FAILURE HANDLING: corrupt JSON → .bad/ folder (slack_queue/.bad/). Eye holds nothing -- restart resumes from files automatically.
  12. LEGACY MIGRATION: replace direct EyeMcpClient.CallFireAndForget(['prompt','send',...]) with WkNotify(WkNotification.ToPrompt(text, cwd)). Tier1: AppBotEyeClaudeStatusStreamer.cs 309/324/348, AppBotEyeGlobalMode.cs 1167, AppBotEyeSlackHandlers.cs 179.
  13. SCHEDULER: homework reminder dedup via process-wide hash (_lastHomeworkHash) + Monitor.TryEnter lock. StampHomeworkFire() called on ALL exit paths (success/fail/exception) to block 8x sibling-instance stampede. Cooldown: 10min per payload hash.
