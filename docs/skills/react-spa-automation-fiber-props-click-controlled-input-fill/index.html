React SPA Automation: fiber props click + controlled input fill

How to interact with React SPAs that block isTrusted=false synthetic events. Use __reactProps onClick/onChange directly from fiber, not dispatchEvent. Covers modal open, input fill, button click, and clipboard capture.

user/developer

Steps

  1. 1. React SPAs often check event.isTrusted in click handlers -- synthetic dispatchEvent calls are silently ignored. Use React fiber props instead.
  2. 2. Open a React button's action: var propsKey = Object.keys(btn).find(k=>k.startsWith('__reactProps')); btn[propsKey].onClick({type:'click',bubbles:true,cancelable:true,preventDefault:()=>{},stopPropagation:()=>{}});
  3. 3. Fill a React controlled input: var nv=Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value'); nv.set.call(inp,'value'); inp.dispatchEvent(new Event('input',{bubbles:true})); -- this updates DOM value AND triggers React onChange pipeline
  4. 4. If nativeInputValueSetter alone doesn't update React state, also call the React onChange handler: var fiberKey=Object.keys(inp).find(k=>k.startsWith('__reactFiber')); var props=inp[fiberKey].memoizedProps; props.onChange({target:{value:'text'},currentTarget:{value:'text'},type:'change',bubbles:true});
  5. 5. IMPORTANT: document.querySelector('input') may return a hidden checkbox/offscreen input. Always check getBoundingClientRect() x/y. Use querySelectorAll('input')[N] to target the visible one (x>0, y>0).
  6. 6. To capture clipboard after copy button: hook BEFORE click in same eval: window.__key=null; var orig=navigator.clipboard.writeText.bind(navigator.clipboard); navigator.clipboard.writeText=function(t){window.__key=t; return orig(t);}; -- then click the copy element in the same eval call.
  7. 7. Some copy buttons open a native window.prompt dialog instead of clipboard API. In that case wkappbot a11y screenshot will show a dialog with the full value -- read it visually from the screenshot.
  8. 8. Distinguish copy vs delete buttons: inspect aria-label. Delete buttons have aria-label='Delete API key'. Copy icons are SVG[aria-label='copy icon'] inside a DIV (not a BUTTON). The parent DIV has the onClick in __reactProps.
  9. 9. To open modal: dispatch full mouse event sequence on the trigger button: ['pointerover','pointerenter','mouseover','mouseenter','pointermove','mousemove','pointerdown','mousedown','pointerup','mouseup','click'].forEach(type => { btn.dispatchEvent(new MouseEvent(type,{bubbles:true,cancelable:true,view:window,clientX:cx,clientY:cy,buttons:type.includes('down')?1:0})); });
  10. 10. After modal opens, the input is usually auto-focused (document.activeElement===input). Fill via nativeInputValueSetter + trigger onChange via fiber. Then call the submit button's __reactProps.onClick.
  11. 11. For CDP CSS selector trusted click (wkappbot a11y click 'hwnd:0xXXXX#button.classname'): use :first-of-type or :last-of-type to target specific buttons. This produces isTrusted=true events via CDP Input.dispatchMouseEvent.
