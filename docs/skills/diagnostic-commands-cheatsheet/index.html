Diagnostic Commands Cheatsheet (whisper validate claude-usage eye tick)

Operator reference for diagnostic and introspection verbs: whisper (real-time speech plus offline pipeline), validate (scenario YAML syntax check), claude-usage (session ctx percent from JSONL size), eye tick (one-shot Eye probe). Use these to assess system health before running heavier automation.

Steps

  1. whisper dictate --target GRAP --lang ko or en --confidence N --no-space --enter: live speech-to-text into focused control. Runs until Ctrl+C. Use for hands-free HTS order entry
  2. whisper study --batch N --for DURATION --engine gemini or gpt: batch-transcribe MP3 segments via AI. Use for auditing recorded sessions
  3. whisper pipeline --loop or --once --for DURATION --script PATH: stable orchestration (study then auto-slice then phoneme harvest). --once runs a single scan; default loops until Ctrl+C
  4. whisper slice or clean or index with --split: offline-only segment processing. Run after pipeline produces new MP3s
  5. whisper phoneme-search --db DIR --query FILE_OR_TEXT --top N: rank phoneme_db candidates. --no-harvest prevents incorporating the query back
  6. validate SCENARIO_YAML: YAML scenario syntax check WITHOUT executing. Use before wkappbot run to catch indent or quote or action-name errors early
  7. claude-usage: prints current session JSONL size and ctx percent (JSONL divided by 20MB). Handoff threshold at 8MB (40 percent) urgent at 10MB (50 percent). Integrated into eye tick output automatically
  8. eye tick: one-shot Eye status query including ctx percent mode prompt source cache. IPC fast-path when Eye alive (typical total 40ms)
  9. --sudo eye tick: same as eye tick but via admin Eye pipe. Shows admin-side state (orphan count hot-swap defer) and helps diagnose when admin Eye itself is stuck
  10. windows FILTER --deep --process NAME --cmd SUBSTR: enumerate top-level windows. Most flexible introspection -- use to confirm a target exists before automating
  11. logcat REGEX --past Nh -f --timeout N --json: tail wkappbot-core logs. -f follows new writes (like tail -f). --past looks back N hours
  12. gc PATTERN --days N --sweep: cleanup stale logs cache runtime files. --sweep is destructive -- review first without the flag
  13. skill audit --app X: cross-check all skills for stale source_refs that no longer match code. Run periodically after refactors
  14. skill verify ID: check a single skill source_refs still match the code. Use after editing a ref target file
  15. Diagnostic decision tree: system feels stuck then start with eye tick (is Eye alive?) then claude-usage (session getting full?) then windows (target exists?) then logcat -f (what is the core saying right now)
  16. Healthy baseline: eye tick total under 100ms ctx under 40 percent windows enumerates in under 500ms. Deviations from these baselines signal which layer needs attention
  17. Maintainer sync (2026-05-01): HQ copy is authoritative.
  18. EYE / HOT-SWAP LIFECYCLE COMMANDS (force-swap + restart): Normal swap trigger: wkappbot --version (Launcher FSW picks up .new.exe, ~auto) Manual swap check: wkappbot hotswap (explicit FSW trigger, no --sudo needed) Staged check: ls bin/wkappbot-core.new.exe (exists = publish done, swap pending) Admin force-swap: wkappbot --sudo --force-swap eye tick When to use: Launcher FSW stuck, admin orphan blocking rename, .new.exe not consumed. What it does: elevated Core renames live exe -> .old-<ts>.exe, copies .new.exe -> live exe. Kills orphan wkappbot-core processes (spares Eye PID, wkchat sessions, self). Reads Eye PID from wkappbot.hq/runtime/eye_ticks.jsonl (last 'Tag':'eye' entry). --force flag also terminates Eye + WhisperRing so they respawn from fresh exe. Lag guard: only acts if .new.exe is >=60s newer than live exe (avoids FSW race). Use --force to bypass lag guard when you need immediate swap. Eye safe restart: wkappbot --sudo eye restart (lifecycle-safe, shows callout) Eye tick with admin: wkappbot --sudo eye tick (shows admin pipe state + orphan count) When swap is stuck: (1) check ls .new.exe exists, (2) wkappbot --sudo --force-swap eye tick, (3) if Eye still on old version: wkappbot --sudo --force eye restart.
