speak --bg: interrupt via X / ESC / caller-exit

speak --bg now supports mid-playback stop: X button on karaoke overlay, ESC key, Alt-F4, or --caller-pid process exit. stopSignal replaces Thread.Sleep so any trigger immediately cuts audio. --bg prints launched pid=N for scripting.

user/developer

Steps

  1. speak --bg: spawns child process and prints '[SPEAK] launched pid=N caller=M' for scripting/grep
  2. SpeakOverlayWindow: X button (closeBtn, top-right, Focusable=false) signals stop immediately
  3. ESC key and window close (Alt-F4/Closing) also trigger RequestStop -- all paths are idempotent
  4. stopSignal (ManualResetEventSlim) replaces Thread.Sleep: stopSignal.Wait(totalMs) + player.Stop() cuts audio
  5. caller-exit watch: --caller-pid <pid> starts 500ms timer; when caller process exits, TTS stops automatically
