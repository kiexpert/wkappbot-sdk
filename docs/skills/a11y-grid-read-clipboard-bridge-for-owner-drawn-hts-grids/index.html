a11y grid-read: clipboard bridge for owner-drawn grids

MFC/GDI owner-drawn grids (HTS realtime tables) have no UIA/MSAA cell nodes. a11y grid-read focuses target, clears clipboard, sends Ctrl+A/Ctrl+C via SendInput, polls clipboard up to 2s, prints TSV verbatim. Override hotkey via --text.

user/developer
a11ygrid-readhtsmfcowner-drawnclipboardfocusless-first

Steps

  1. Locate grid via grap (e.g. '*Hero*/Form1101/*grid*')
  2. a11y grid-read <grap> -- runs default Ctrl+A,Ctrl+C chord
  3. Custom chord via --text 'ctrl+shift+c' for apps with dedicated 'copy all' binding
  4. Clipboard polled for up to 2s; TSV dumped to stdout on success
  5. If empty clipboard after timeout the app did not honor the chord -- probe the right hotkey via the app's menu
  6. 100pct accuracy -- no OCR error, values come from the app's own copy path
  7. Usage example: wkappbot a11y read '*Hero*/grid-area' returns only container; use wkappbot a11y grid-read '*Hero*/grid-area' for TSV cells
