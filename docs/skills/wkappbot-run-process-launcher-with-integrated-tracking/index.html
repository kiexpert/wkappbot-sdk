wkappbot run: process launcher with integrated tracking

FEATURE: wkappbot run <exe> [args] would launch a process with integrated bug tracking (auto-suggest on crash), close detection (exit code logging), and optionally attach UIA monitoring. Similar to cargo run or dotnet run but for arbitrary exes.

user/developer

Steps

  1. Launches exe via AppBotPipe.Spawn() with WKAPPBOT_LAUNCH=1 env var so child can detect it.
  2. Monitors child exit: non-zero -> auto-file suggest via bug-auto with exit code + last stderr lines.
  3. Optional --uia flag attaches UIA event listener to first window found with matching PID, logs focus/state changes.
