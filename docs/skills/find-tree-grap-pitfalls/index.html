wkappbot find -- Tree Output Design & Grap Pitfalls

Hard-won lessons from implementing find tree: grap candidate scoring, Afx MFC class detection, glob char-class pitfall in PatternMatcher, hwnd fallback strategy. 2026-04-23.

user/developer
findgraptreepatternmatcherglobhwndmfclegacy

Steps

  1. [FIND-TREE-DEFAULT] wkappbot find <keyword> outputs Win32+UIA grap path tree by default (no flag). Each line = copy-paste ready grap. Win32 levels use "/". UIA suffix after "#". "#" ALWAYS present before UIA nodes. grap "title" == "*title*" -- contains-match by default, "*" wrapping is redundant noise. EXAMPLE: "영웅문Global" "영웅문Global"/MDIClient/"[2000] 해외주식 주문종합" "영웅문Global"/MDIClient/"[2000] 해외주식 주문종합"/AfxFrameOrView110 "영웅문Global"/MDIClient/"[2000] 해외주식 주문종합"/AfxFrameOrView110#Button_ok
  2. [AFX-CLASS-GENERIC] MFC MDI auto-generated class: Afx:XXXXXXXX:b:... -- ALL MDI children share same class, useless as identifier. DETECT: Regex ^Afx:[0-9A-Fa-f] -> IsGenericClassName=true -> fall back to window title. RESULT: "[2000] 해외주식 주문종합" (title) shown instead of "Afx:006A0000:b:..." (class). Any class matching Afx:[HEX] prefix is MFC auto-generated, not stable.
  3. [GRAP-CANDIDATE-SCORING] BuildTreeSegment picks most intuitive from multiple candidates. Title score: 100 - min(len,40) + 40(Korean) + 10(letter) - 50(0x prefix) - 20(path separators). Class score: 60 - min(len,30) + 20(PascalCase) - 5(digits) - 40(colon = auto-generated). WINNER: Korean title > short title > PascalCase class > generic class. hwnd is NEVER a candidate -- changes every session.
  4. [GLOB-PITFALL] PatternMatcher treats "[", "]" as glob char classes. "[2000] 해외주식" -- [2000] = char class {2,0}, NOT literal "[2000]". PatternMatcher.Create("[2000] 해외주식").IsMatch("[2000] 해외주식") returns FALSE. Do NOT use PatternMatcher to self-verify grap built from titles with "[" or "]". FIX: plain Contains: title.Contains(innerText, OrdinalIgnoreCase). Glob-special: "[", "]", "*", "?". Safe alt: JSON5 {proc:'nfrunlite',title:'주문종합'}.
  5. [HWND-FALLBACK-STRATEGY] hwnd changes on every restart -- never use as primary grap. STRATEGY: 1) Build candidates by score. 2) Verify with plain Contains (not PatternMatcher). 3) First passing -> emit. 4) All fail -> {proc:'name',hwnd:0x...} as VISIBLE session-scoped fallback. Never silently emit hwnd as stable -- {proc,hwnd} signals fragility to caller.
