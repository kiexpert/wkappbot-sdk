Developer Skill Template

Template for skills that help developers change code, refactor implementation, add tests, and ship behavior safely.

developer
skilltemplatedevelopercodetestbuildrefactorverify

Steps

  1. Classify the skill as developer-facing before writing anything else.
  2. State the implementation job in one sentence: change code, refactor, test, debug, or ship behavior.
  3. Keep the steps short, executable, and testable; include build or test verification when the skill changes state.
  4. Prefer concrete file paths, commands, and acceptance criteria over broad advice.
  5. If the skill includes operational checks, keep them minimal and secondary to the implementation flow.
  6. If a rule starts being reused across repositories, extract the common part into a project or operator skill and keep this one focused on implementation.
