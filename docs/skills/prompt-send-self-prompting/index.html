prompt send -- Self-Prompting & Agent Notification

How to deliver prompts to a running Claude Code / Codex window. Use prompt send for self-prompting, scheduled nudges, and agent notifications. FindAllPrompts detects the input box via UIA; the input is hidden while the agent is busy -- always use --when-idle when the agent may be mid-execution.

Steps

  1. [CORE] prompt send "<name>" "<message>" -- injects message into a running Claude Code or Codex window and submits. <name> matches CWD folder tag (e.g. WG-WKAppBot) or display name substring.
  2. [DISCOVERY] prompt list -- show all detectable AI windows (hwnd, host type, display name). Only windows where the input element is currently visible and enabled are returned.
  3. [WHY-IDLE] FindAllPrompts() uses UIA to find [Edit] 'Message input'. When the agent is busy (executing a tool), this element is disabled/hidden -> FindAllPrompts returns 0 -> delivery fails silently.
  4. [WHEN-IDLE] prompt send "<name>" "<msg>" --when-idle 5s -- polls every 1s until the input has been idle >= 5s, then delivers. Use this whenever the agent might be mid-execution.
  5. [AFTER] prompt send "<name>" "<msg>" --after 10s -- waits a fixed delay then delivers. Use for startup sequences or when idle state is predictable.
  6. [TIMEOUT] --timeout 5m (default 30m) -- how long --when-idle keeps polling before giving up. Set short for non-critical nudges, long for important deliveries.
  7. [FOCUSLESS] VS Code Claude Code delivery path: UIA TextPattern2.InsertTextAtSelection (truly focusless) + WM_KEYDOWN Enter to renderer. No focus steal, no clipboard clobber. Works even if another window is foreground.
  8. [FOCUS-STEAL] If TextPattern2 fails, fallback: SmartSetForegroundWindow + clipboard paste + Enter. ClipboardGuard prevents clobbering an ongoing paste. AllowFocusSteal=true required for this path.
  9. [FROM-EYE] Eye background tasks (skill audit, homework) use EyeMcpClient.CallFireAndForget + --when-idle so delivery waits for agent idle without blocking Eye's main loop.
  10. [SELF-PROMPT] To notify the current agent from a script or tool: wkappbot prompt send "WG-WKAppBot" "[REMINDER] ..." --when-idle 5s --timeout 2m
  11. [TROUBLESHOOT] exit 1 + 'No prompt windows found': agent is busy -> add --when-idle 5s. 'No window matched': check wkappbot prompt list for exact display names. TextPattern2 fail: VS Code update may have changed UIA tree -- check [Edit] 'Message input' still exists with a11y inspect.
