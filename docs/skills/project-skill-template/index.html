Project Skill Template

Template for skills that capture repository-specific rules, exceptions, and local conventions so the right project-only guidance is easy to select.

user/developer
skilltemplateprojectrepositorylocalconventionssplitverify

Steps

  1. Classify the skill as project-specific before writing anything else.
  2. Keep only the rules that are specific to one repository, product, or local runtime.
  3. Separate shared operator guidance from project exceptions so the skill stays short and reusable.
  4. Include the minimum verification step needed to prove the project rule still holds.
  5. Prefer project names, file paths, and commands that are valid only inside the target repository.
  6. If a rule starts being reused elsewhere, extract the common part into an operator or developer skill and keep the project skill narrow.
  7. Avoid generic advice that should live in an operator or developer template instead.
