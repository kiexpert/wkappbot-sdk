License pending invite: detect and guide user to accept

When GitHub collaborator invite is pending (not yet accepted), GET /repos/invitations returns permission=none -- indistinguishable from never-invited. Fix: check invitations endpoint before falling back to Free tier. UX: show Eye callout + numbered console guide so paying users are not silently downgraded.
