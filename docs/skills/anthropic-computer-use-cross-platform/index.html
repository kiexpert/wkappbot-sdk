AGENT LOOP PATTERN (simplified Python) while True and iterations less than max_iterations: response = client.beta.messages.create( model=model, tools=tools, messages=messages, betas=[beta_flag], max_tokens=max_tokens) messages.append({role: assistant, content: response.content}) tool_results = [] for block in response.content: if block.type == tool_use: result = handle_computer_action(block.name, block.input) tool_results.append({type: tool_result, tool_use_id: block.id, content: result}) if not tool_results: break messages.append({role: user, content: tool_results}) Iteration cap prevents runaway API costs. Screenshot after every action is expensive batch when possible.
  6. COORDINATE SCALING (CRITICAL GOTCHA) API caps images at 1568px longest edge and about 1.15M total pixels. A 1512x982 screen is downsampled to about 1330x864 before Claude sees it. Claude returns coordinates in downsampled space, your click handler runs in real screen space. Fix: compute scale factor once, downscale screenshots BEFORE send, upscale click coords before execute. def get_scale_factor(w, h): long_edge_scale = 1568 / max(w, h) pixel_scale = math.sqrt(1_150_000 / (w * h)) return min(1.0, long_edge_scale, pixel_scale) Skipping this causes clicks to miss by offset proportional to ratio. Silent bug, easy to miss.

SECURITY, LIMITATIONS, AND MITIGATIONS Known risks: Prompt injection from page content or images can override user instructions Classifier auto-flags suspected injections and asks for confirmation You can opt out of classifier via Anthropic support (not recommended) Claude may hallucinate coordinates (mitigated by reasoning/thinking in 4.x) Spreadsheet cell selection still imperfect even with fine-grained mouse Recommended mitigations: Run inside dedicated VM or container with minimal privileges No sensitive data or credentials in accessible files Allowlist internet domains if possible Human-in-the-loop confirmation for transactions, cookie consent, ToS Keep resolution at XGA (1024x768) or WXGA (1280x800) for best accuracy Log every action for post-incident forensic Current limitations (Apr 2026): Latency too slow for real-time interactive work OSWorld benchmark: Anthropic 22 percent vs human 72 percent Account creation and social platform impersonation deliberately constrained Niche app reliability lower than mainstream app reliability
