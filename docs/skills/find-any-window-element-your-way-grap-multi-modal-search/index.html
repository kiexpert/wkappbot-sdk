Steps

  1. grap is a multi-modal pattern: glob wildcards (*Button*), OR via semicolon (*notepad*;*calc*), UIA scope via #panel (app#realtime-account), tab portal (Chrome#ChatGPT#model), JSON5 ({title:'Claude',domain:'claude.ai'}), and direct hwnd:0xNNN.
  2. Combine forms with AND semantics: *order*#account means a window matching '*order*' globally then narrowed to UIA element 'account' inside it. Multi-field JSON5 acts as AND across keys (proc + domain + title).
  3. Adb scheme adb://device/*screen*#balance routes the same syntax to an Android device tree. The 'a11y find' command prints '# TARGET hwnd:0x...' as the first line for copy-paste reuse.
  4. OR INTERNALS + --all PATTERN (2026-05-18): ; OR uses coverage-sum ranking (same SkillCoverageScore as skill search). A window matching MORE of your ; patterns scores HIGHER -- not just first-match.
