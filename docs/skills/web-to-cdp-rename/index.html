web command renamed to cdp -- web kept as deprecated alias

The browser-control command `wkappbot web` was renamed to `wkappbot cdp` 2026-05-05 (commit 4ddcd5a4) so the help text and skill docs match the actual transport (Chrome DevTools Protocol). `wkappbot web ...` still works but emits a deprecation warning to stderr and routes to the same handler. CommandHelp.cs --help text and AskCommands.Loop.Persona prompt both refer to `cdp` as primary and `web` as deprecated alias.

Steps

  1. [NAMING RATIONALE] `web` was ambiguous (HTTP fetch? webbrowser? web server?). Actual transport is Chrome DevTools Protocol websocket. New name `cdp` is unambiguous and matches the existing CdpClient/CdpConnection/EnsureCdpConnection naming throughout the codebase. Help text now reads `cdp open [url]`, `cdp list`, `cdp eval`, etc.
  2. [ALIAS BEHAVIOR] Top-level dispatcher accepts both `cdp` (primary) and `web` (deprecated). When `web` is used, stderr prints a one-line warning '[CDP] note: "web" is now "cdp"; please update scripts' but execution continues normally on the same handler. No breaking change for existing scripts/skills/agents.
  3. [HELP TEXT UPDATED] CommandHelp.cs:506 lists `cdp open [url] [--port N] [--headless] [--no-launch]` as the canonical form. The Skills+News surface, suggest evidence scripts, and AskCommands persona prompt (AskCommands.Loop.Persona.cs:242 'CDP TOOLS (was "web" -- now "cdp"; "web" still accepted as deprecated alias):') were all updated in the same commit.
  4. [SKILL DOCS UPDATED] All wkappbot-webbot skills referring to the `web` command were updated to `cdp` (e.g. cdp-port-isolation-window-property.skill.json, ask-web-chrome-launch-focusless-guard-allowlist.skill.json). Search the project for 'wkappbot web ' and update any remaining occurrences when adding new skills/docs.
  5. [CALLER MIGRATION] Update local scripts: replace `wkappbot web open ...` -> `wkappbot cdp open ...`. Replace `wkappbot web list` -> `wkappbot cdp list`. Replace `wkappbot web eval ...` -> `wkappbot cdp eval ...`. Persona prompt change is automatic (next AI session reads new persona). The deprecation warning gives a window for migration; there is currently no removal date.
  6. [VERIFY] Run `wkappbot --help | grep cdp` -- should show cdp commands. Run `wkappbot web list` -- should print a deprecation note then succeed. Run `wkappbot cdp list` -- should succeed without any warning.
