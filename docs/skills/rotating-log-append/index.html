Rotating Log Append Helper

Shared append helper for runtime logs and JSONL files. If the target file was created on a previous day, rotate it into .old-append/YYYYMMDD/ before appending new content.

user/developer
appendrotatelogjsonlruntimetelemetryold-appendhelper

Steps

  1. WHEN TO RUN: use this when adding or modifying any shared append helper for logs, JSONL, telemetry, or runtime traces.
  2. ROTATION RULE: if the target file exists and its creation date is not today, move it under the same parent folder's .old-append/YYYYMMDD/ directory before appending.
  3. NAME RULE: preserve the original filename inside .old-append/YYYYMMDD/. If that name already exists, add a -2, -3, ... suffix before the extension.
  4. APPEND RULE: after rotation, append the new line to the fresh target file using UTF-8 without BOM.
  5. FAILURE RULE: rotation is best-effort; if move fails, keep appending to the live file rather than losing the write.
  6. INTEGRATION RULE: use one canonical helper for all recurring append sites. Do not duplicate rotation logic at each call site.
  7. VERIFY: create a stale file dated yesterday, append one line, confirm the old file is in .old-append/YYYYMMDD/ and the live file contains the new line.
