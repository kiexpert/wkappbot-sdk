screensaver command -- launch, close, and Eye integration

wkappbot screensaver: launch WPF sunset overlay (idle 10s+, per-monitor) or wipe all screensaver windows (4-pass close). Eye spawns automatically; use screensaver close to dismiss manually.

Steps

  1. USAGE: wkappbot screensaver (no args=launch overlay). wkappbot screensaver close (dismiss all). No other subcommands. Source: ScreenSaverStandaloneCommand.cs
  2. CLOSE cmd: wkappbot screensaver close immediately removes ALL covering windows -- own screensaver AND other programs overlays. 4-pass wipe: (1) Enum WKAppBot ScreenSaver windows -- wipe. (2) Black fullscreen detect: 3x3 pixel grid avgY<30, 90pct+ work area, x3 retries. (3) Kill wkappbot-core procs with screensaver in cmdline. (4) Sleep 300ms + rescan. Each wipe: alpha=0, SW_HIDE, move off-screen, WM_CLOSE. After: SendInput mouse-move resets idle timer (~10s).
  3. LAUNCH: Eye spawns on idle>=10s via --from-eye flag. One WPF overlay per monitor. ShowActivated=false (no focus steal), WS_EX_TRANSPARENT (click-through). Sunset progression: 10s=golden, 60s=red, 90s=purple, 120s=night sky with stars+moon+waves. Auto-exits on any user input (9-layer kill). Polls WKAPPBOT_PARENT_PID every 500ms -- exits if Eye dies.
  4. EYE INTEGRATION: Eye writes runtime/eye_busy file during CDP/MCP automation -- screensaver hides while file exists. Eye spawns via AppBotPipe.Spawn(path, screensaver --from-eye) on idle expiry. WKAPPBOT_PARENT_PID env var set for parent-alive polling.
  5. TROUBLESHOOTING: (a) screensaver will not close -- use wkappbot screensaver close, NOT a11y close or a11y kill (cannot find the window). (b) Black fullscreen from third-party -- Pass2 pixel sampling handles it. (c) Re-triggers immediately -- SendInput grace ~10s, wait a moment. (d) Screensaver during automation -- Eye sets eye_busy to suppress.
  6. DISABLED STATE: if wkappbot screensaver outputs [SCREENSAVER] Disabled by WKAPPBOT_NO_SCREENSAVER=1, the env var is set in Windows User environment (not in any config file). Fix via PS: [Environment]::SetEnvironmentVariable('WKAPPBOT_NO_SCREENSAVER', null, 'User') then restart Eye. Or via cmd: reg delete HKCU\Environment /v WKAPPBOT_NO_SCREENSAVER /f then reopen terminal.
  7. PERIODIC OVERLAY REMOVAL (while active): SS-Master watchdog thread in ScreenSaverOverlay.Lifecycle.cs runs WipeBlockingOverlays() every 30s while screensaver is visible. Target = OTHER programs overlays only (NOT own screensaver). Known blockers killed regardless of size: NVIDIA Overlay, nvsphelper64, nvcontainer, TextInputHost. Unknown procs: removed if covering >=75% screen width+height. Wipe: alpha=0, SW_HIDE, (-32000,-32000), WM_CLOSE. Log: [SS:WIPE] 0xHWND pid=N proc=name knownBlocker=true/false
