  1. [THREAD-CONTRACT] Fixed slot layout: root=앱봇아이 status (🟢 Eye alive PID/uptime/mem/frame). [0]=앱봇아이 card reply (IPC summary / active card content). [1]=CCABot mouse+CCA live analysis. Thread reused across restarts -- never post new root if existing 앱봇아이 msg found (FindEyeStatusTsForReuse).

  3. [CCA-REUSE] CCA reply reuse: search by username=='앱봇아이' via FirstOrDefault -- NOT by index. Bug history: children[1] hardcoded -> fails when card slot absent or thread has extra replies. _mouseCcaReplyTs holds ts; UpdateMouseCcaSlack() edits in-place via SlackUpdateMessageAsync(). New post only when ts==null.
