Steps

  1. Create a GitHub account at github.com/signup (required - license check uses gh CLI under the hood; without an account you cannot upgrade beyond Free).
  2. Install gh CLI: Windows -> 'winget install --id GitHub.cli'; macOS -> 'brew install gh'; Linux -> see cli.github.com/manual/installation.
  3. Authenticate: run 'gh auth login', choose GitHub.com, HTTPS, 'Login with a web browser', complete the device-code flow in browser.
  4. Download wkappbot: 'gh release download --repo ***/wkappbot-sdk --pattern *.zip' (downloads the latest wkappbot-X.Y.Z.zip into the current directory).
  5. Install: extract the zip into %USERPROFILE%\.wkappbot\bin (or any path), add that bin directory to PATH; alternatively run install.cmd from the extracted folder.
  6. Verify install: open a fresh terminal and run 'wkappbot --version' - it should print the version string and exit 0.
  7. Check license: 'wkappbot license status' - on a fresh install this shows tier=Free with no pending invites; all base features (a11y, inspect, run, scenario, skill, speak, file, logcat) are already usable.
  8. Upgrade (optional): follow SUBSCRIBE.md - bank-transfer 100k KRW (CDP) or 500k KRW (Sudo) to KIS with your GitHub username as the memo, wait up to 1 hour, accept the GitHub collaborator invite at github.com/notifications, re-run 'wkappbot license status' to confirm tier upgrade.
  9. First automation: 'wkappbot windows' or 'wkappbot a11y windows' shows wkappbot-related windows (default filter: wkappbot*). Use 'wkappbot windows *' or 'wkappbot a11y find *' to list ALL visible top-level windows. Confirms the Win32/UIA pipeline is working end-to-end.
  10. Correct default behavior: 'wkappbot windows' (no args) = wkappbot* filter. Use 'wkappbot windows *' to list all windows. Old docs said 'lists all' which was incorrect.
