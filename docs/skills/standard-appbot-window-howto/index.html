Standard AppBot Window T2 HowTo

T2 domain tier. FindRectProviderHwnd, IPC __hwnd forwarding, ConPTY hidden-window rect, isBig check, downstream consumers, GAP fixes.

user/developer
Part of: standard-appbot-window

Steps

  1. FindRectProviderHwnd pattern: hForRect = IsWindowVisible(hwnd) ? hwnd : GetAncestor(hwnd, GA_ROOTOWNER). Returns placement-ready CASCADIA for ConPTY hidden windows. Hidden hwnd kept for input injection identity.
  2. ConPTY PseudoConsoleWindow: class=PseudoConsoleWindow, IsWindowVisible=false, no title, but IsWindow=true and non-zero GetWindowRect. P2 finds it (no visibility filter). GA_ROOTOWNER -> CASCADIA for rect.
  3. isBig check: ancestors must pass GetWindowRect size >= 200x100 to avoid ConPTY tiny 16x16 rect. Skips hidden pseudo-console, lands on real terminal CASCADIA window.
  4. IPC __hwnd: EyeCmdPipeClient.ResolveCallerTerminalHwnd() -> if hwnd!=Zero prepend __hwnd:0xHHHH to args JSON. EyeCmdPipeServer strips prefix, validates IsWindow, sets CallerHwnd AsyncLocal + ChromeLauncher.CallerHwndForPlacement static.
  5. DOWNSTREAM CONSUMERS: TryMoveChromeToCallerAsync (placement), ChromeLauncher.CallerHwndForPlacement (static anchor), MCP worker _meta.callerHwnd, Admin Eye ElevatedEyeServer, WKAPPBOT_CALLER_HWND env var to Core subprocess.
  6. ICONIFIED CALLER: if terminal minimized -> TryMoveChromeToCaller skips placement. Chrome stays at last valid position. Background/batch run = moving Chrome disruptive.
