Steps

  1. Always inspect before automating an unfamiliar app; use find to discover not guess
  2. Treat a11y find as a contract: one shared focus line one target block per match optional info lines shell-safe grap and verify by rerunning on the emitted hwnd token
  3. Separate root hwnd from process-owned hwnd; process identity comes from the matched proc/domain/cmd/title/cls/file not the host shell
  4. Prefer focusless tiers first: UIA Invoke/Value/Toggle/Select then Win32 PostMessage then SendInput only if necessary
  5. For browser targets prefer CSS then CDP then UIA; use the exact hwnd grap from find when the tab or frame matters
  6. Keep the grap short quoted and paste-ready for both Claude and Codex; if ambiguity remains rerun inspect/find before acting
