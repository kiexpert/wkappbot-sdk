Steps

  1. INITIAL SETUP: git clone wkappbot-sdk. pip install nothing needed (stdlib only). Ensure D:/GitHub/WKAppBot/bin/wkappbot.hq/skills/ exists (HQ skill catalog). Set GH_PAT env var for Pages status check and OAuth.
  2. BUILD: python scripts/build-skill-page.py -- auto-finds HQ catalog, filters apps, masks secrets, writes docs/skills/index.html. Run after any skill changes to refresh.
  3. GITHUB PAGES: Settings > Pages > Source: main branch /docs. URL: https://***.github.io/wkappbot-sdk/. Check: gh api repos/.../pages
  4. grep status.
  5. GHA TRIGGER FROM CORE: add .github/workflows/notify-sdk.yml to Core repo with repository_dispatch event skill-catalog-updated targeting ***/wkappbot-sdk. SDK workflow listens and rebuilds.
  6. PRO SUBSCRIBER MGMT: gh api repos/***/wkappbot-harness/collaborators -X PUT -f permission=pull to add subscriber. Remove: gh api repos/.../collaborators/USERNAME -X DELETE. Payment flow via payment-to-license-activation skill.
  7. LAYOUT CUSTOMIZATION: edit docs/skills/index.html JS section HERO_QUOTE to change reflection text. Edit CSS var --accent for brand color. Edit CATEGORY_MAP in skills-data.js for grouping.
  8. HARNESS MONETIZATION: Free=view skill titles+preview. Pro=full steps+no blur. Enterprise=custom skill tree. Subscription = GitHub collaborator on wkappbot-harness private repo.
