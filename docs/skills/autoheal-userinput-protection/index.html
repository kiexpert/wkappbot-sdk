  3. 2. [MANDATORY] Restore trigger = end of each ask/CDP action only. Watchdog = monitor+notify only.

[FOCUSLESS PATTERN] WARNING: Emulation.setFocusEmulationEnabled(true) is Blink-renderer only -- does NOT prevent OS SetForegroundWindow from Page.bringToFront (path: WebContents::Activate->BrowserFrameViewWin->SetForegroundWindow). Role: auxiliary only (satisfies page-internal JS focus events). SW_SHOWMINNOACTIVE(8) is still the primary OS-level prevention. Pattern: (a) visibilityState=visible->skip, (b) SW(8), (c) WaitForWindowStateAsync(minimized, 1000ms), (d) EmulateActiveTabAsync(), (e) CDP call, (f) RestoreChromeNoActivate SW(4), (g) WaitForWindowStateAsync(normal, 1000ms). Degraded: timeout on (c)/(g) -> proceed CDP-only. Chrome M119-121: setWebLifecycleState(active) may intermittently reset visibilityState to hidden. M122+ stable.
