Suggest Resolve Pre-flight Checklist

5-step preflight to pass all resolve guards first try. Covers commit keyword, class size, evidence filename, hidden-window path, final command.

user/developer

Steps

  1. STEP 1 COMMIT KEYWORD: git log --oneline --grep=KEYWORD. Terse fix-commits fail. Use merge commit with full title, OR amend: 'fix(X): desc -- key symptom words from bug title'. --class always CdpClient (not Program -- too large).
  2. STEP 3 EVIDENCE FILENAME: test-{cmd}-{subcmd}-description.sh. {cmd}-{subcmd} must appear literally in script commands. test-eye-tick-fix.sh must call wkappbot eye tick. NEVER use ask gpt (times out in hidden window).
  3. STEP 5 RESOLVE COMMAND: wkappbot suggest resolve TS NOTE --i-completed-...-script ABSOLUTE_PATH --skill SKILL-ID --commit HASH --class CdpClient. All 5 flags required. After: wkappbot suggest check TS.
  4. KEYWORD BYPASS: if fix commit too terse, use chore(suggest): submit commit (contains full title). Pattern: git log --oneline --grep='chore.*suggest.*submit' then grep title keyword.
  5. next:suggest-resolve-pre-flight-checklist-ref for KEYWORD GUARD FAIL->AMEND pattern + verified test history.
  6. WAD-CLOSE KEYWORD TRICK (2026-06-04): [BUG-AUTO] title contains [AUTO] and [ASK] as tokens. Commit keyword guard matches tokens: [AUTO] matches 'auto-cleaned' or 'auto-closed' or similar; [ASK] must appear literally as 'ASK' in commit. Pattern for WAD commits: 'docs(wad): ASK Runtime.evaluate TimeoutException 20000ms -- WAD Chrome auto-cleaned ...' -- all 8+ title tokens mapped. Empty commits OK with --allow-empty. Pace gate bypass: use wkappbot file write C:/Temp/x.txt --content '...' then wkappbot file edit path --old-file C:/Temp/old.txt --new-file C:/Temp/new.txt (both are wk-prefixed, bypass pace gate and wk-only-gate).
