Think Eye: per-workspace VS Code status card overlay

EyeCard WPF overlay spawned by Eye per VS Code window. Upper-right 5px. Dim 50% unfocused, transparent hover-when-focused, WS_EX_TRANSPARENT click-through, IsIconic hide on minimize. GetCursorPos poll avoids MouseEnter/Leave flicker.

eyeoverlaywpfvscodethink-eye

Steps

  1. EyeCard is a tiny WPF overlay spawned by Eye for each VS Code window — anchored 5 px from the upper-right corner, dim 50% when unfocused, transparent on hover when focused.
  2. Click-through is enforced via WS_EX_TRANSPARENT extended style; the card never steals focus and IsIconic() check hides it whenever the parent VS Code window is minimized.
  3. Hover/leave detection uses GetCursorPos() polling instead of WM_MOUSEENTER/LEAVE — eliminates flicker on rapid mouse moves across the overlay boundary.
