QMD Local Codebase Search — Install, Index, and Query

QMD: BM25 + vector semantic + optional LLM reranking local search engine. Pre-indexes C# source, skill JSONs, and docs. Claude resolves qmd://collection/file.cs:42 references directly to file+line, cutting exploration tokens by 91%. MCP server exposes search as mcp__qmd__* tools.

Steps

  1. [WHAT] QMD is a local search engine (BM25 + vector embeddings) that pre-indexes your codebase. Claude uses it to jump directly to the right file:line instead of globbing and grepping the entire repo.
  2. [INSTALL] Install via bun: bun install -g @tobilu/qmd. On Windows, create a wrapper: D:/SDK/bin/qmd.cmd pointing to bun.exe + dist/cli/qmd.js %* . npm install also works but creates shell script wrappers that fail on Windows.
  3. [COLLECTIONS] Add collections from the project root: qmd collection add wkappbot-src --mask **/*.cs , qmd collection add wkappbot-skills --mask **/*.skill.json , qmd collection add wkappbot-docs --mask **/*.md . Use --mask (not --glob) for glob patterns.
  4. [CONTEXT] Add human descriptions to help Claude understand each collection: qmd context add 'WKAppBot C# source...' -- qmd://wkappbot-src/ . This description appears in every search result.
  5. [EMBED] Generate vector embeddings: qmd embed . Downloads 329MB embedding model on first run (embeddinggemma-300M-Q8_0.gguf). Subsequent runs are incremental. Run after adding new files.
  6. [SEARCH-MODES] (1) qmd search TEXT -- BM25 keyword search. Fast, no extra models. Best for identifiers, function names, exact terms. (2) qmd vsearch TEXT -- vector semantic search. Best for concept queries. Needs embedding model. (3) qmd query TEXT -- hybrid + LLM expansion + reranking. Best quality but downloads 2GB extra models on first run. Avoid in daily use.
  7. [MCP] Register in .mcp.json: add 'qmd' server with command=bun.exe and args=[qmd.js, mcp]. Tools become available as mcp__qmd__* in Claude Code. Claude can call search/vsearch/get directly.
  8. [CLAUDE-MD-RULE] Add to CLAUDE.md Token Efficiency section: 'Use qmd search before reading files -- BM25+vector pre-index of all C# + skills + docs (MCP: qmd)'. This prevents blind globbing on every question.
  9. [RESULTS] Result format: qmd://collection/path/file.cs:LINE -- score% -- code snippet. Pass the qmd:// URI to qmd get to see more context. Claude Code resolves these URIs to read exact file sections.
  10. [DAILY-USE] For identifiers/function names: qmd search FunctionName . For concept queries: qmd vsearch 'how does hot swap work' . For multi-collection: omit --collection (searches all). Re-index after bulk edits: qmd update.
  11. [LIMITS] qmd search may return no results for natural language full sentences -- use vsearch instead. qmd query first run is slow (2GB model download). Windows path separator in collection mask must use forward slashes.
