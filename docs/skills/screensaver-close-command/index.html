screensaver close: kill all running screensaver processes

wkappbot screensaver close finds every wkappbot-core process whose command line contains 'screensaver' and sends WM_CLOSE (or Kill if windowless). Eye will respawn screensaver when idle conditions are met again.

user/developer
screensavercloseoverlaywkappbot-coreprocess-management

Steps

  1. Command: wkappbot screensaver close
  2. Dispatch: Program.cs 'screensaver' case checks restArgs[0] == 'close' -> ScreenSaverCloseCommand(). No args -> ScreenSaverStandaloneCommand() (existing behavior unchanged).
  3. Close logic: GetProcessesByName('wkappbot-core') -> GetProcessCommandLine -> Contains('screensaver') -> PostMessageW(WM_CLOSE) if main window exists, else p.Kill(). Reports count closed.
  4. Eye respawn: Eye (AppBotEyeGlobalMode.cs) auto-respawns screensaver when humanIdleMs >= 10000ms. Closing via this command is equivalent to user becoming active -- Eye will restart it next idle cycle.
  5. Use case: force-close stuck screensaver overlay, test screensaver lifecycle, or dismiss before automation that requires clean screen state.
