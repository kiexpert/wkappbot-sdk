Session Pattern Mining and Skill Promotion

Scan recent session logs for repeated successful patterns, score them for durability, and promote only stable knowledge into the right home: CLAUDE.md, AGENTS.md, or a reusable skill.

user/developer
sessionpatterntelemetrypromotionlogscoreminingskill

Steps

  1. Find the most recent relevant session logs in HQ or the workspace, starting with the latest successful runs.
  2. Extract prompt, tools used, outcome, retry count, elapsed time, and failure reason for each candidate pattern.
  3. Group repeated patterns and score them by repeatability, success rate, and cross-session durability. Ignore one-off successes unless they recur.
  4. Promote only stable knowledge. Put Claude-facing project notes in CLAUDE.md, Codex and other shared rules in AGENTS.md, and executable workflows in a skill.
  5. Verify each promoted candidate with the narrowest useful replay or smoke test. If verification is unstable, keep the candidate in HQ only.
  6. Do not auto-promote raw traces. Keep raw logs in HQ and promote only durable summaries, rules, or workflows.
