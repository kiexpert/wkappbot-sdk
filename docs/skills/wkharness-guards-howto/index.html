wkharness-guards How-To

wkharness-guards per-guard unblock steps, escape hatch procedure, guard cascade recovery

user/developer

Steps

  1. G1 ASK-GUARD: wkappbot ask/whisper with run_in_background=true -> blocked. Fix: remove run_in_background from the command. Only for fire-and-forget tasks, not streaming ask.
  2. G2 KILL-GUARD: PS terminate-cmdlet on wkappbot-core/wkchat/wkappbot/wka11y -> blocked. Fix: wkappbot taskkill /IM <exe.exe> to classify. Use --dry-run to preview, --force <pid> for zombie kill.
  3. G3 SKILL-SEARCH-NUDGE: soft exit-0 nudge, not a real block. Action: run wkappbot skill search <topic> first, then grep if insufficient.
  4. G4 SKILL-EDIT-GUARD: direct .skill.json file edit blocked. Fix: wkappbot skill edit <id> for changes. wkappbot skill contribute ... to create new. Never edit .skill.json files directly.
  5. G5 PACE-GUARD: Sonnet%>Total% fires on Edit/Write. Fix: delegate to Agent(model:opus) or Agent(model:haiku) with exact brief. EXEMPT: memory/*.md, project CLAUDE file, AGENTS.md. Check: wkharness.ps1 -Status
  6. G6 CP949-GUARD: non-CP949 chars in Write blocked. Fix: ASCII or Hangul only in Write content.
  7. G7 AGENT-BRIEF-GUARD: fewer than 3 wkappbot skill read lines in Agent prompt -> blocked. Fix: add skill read on-load + skill read wkharness-guards + task-relevant skill. All IDs validated live -- bad ID = blocked.
  8. G8 OPUS-BUDGET-GUARD: Opus at 95% weekly budget -> blocked. Fix: use Agent(model:haiku) with exact brief. Or wait for Thursday 07:00 KST reset.
  9. G9 STALL-GUARD: 300s + 10 calls solo -> blocked. Fix: delegate via Agent tool (resets counter). Read tool exempt. Streak resets on session change or 120s gap.
  10. G10 BG-TASK-GUARD: bg task mark >30s -> blocks next tool. Fix: Read the background output file path -- reading clears the mark. Auto-evict after 10min.
  11. SPEC-GATE: Opus Agent missing SPEC block -> blocked. Fix: prepend SPEC block -- 1.Goal 2.Files 3.Approach 4.Constraints 5.Exit. Block message shows AGENT ROUTING CHEATSHEET.
  12. CLAUDE-MD-SYNC: Agent dispatch without Pending section in project main MD -> blocked. Fix: add ## Pending with checkbox item to project main MD, then retry Agent.
  13. USAGE-TEST-GUARD: 50pct Opus redirect to wkclaude.sh habit trainer. Fix: retry Agent() (50% passes), or run Agent.cmd --model opus with heredoc in Bash.
  14. WKCLAUDE-DIRECT: direct wkclaude.sh/cmd/ps1 call without Agent.cmd -> blocked. Fix: route through Agent.cmd in Bash or Agent() tool.
  15. FULL ESCAPE when all delegation blocked: (1) skill* always exempt from all guards. (2) file-edit wrapper doubly exempt from pace+stall guards. (3) Lead command with wkappbot/git/gh/./wk* -- wk-only-gate checks LEADING TOKEN. (4) After file write: skill edit to clear pending lock, then delegate. (5) For file ops: wkappbot file tool path.
  16. GUARD 3 SKILL-SEARCH-NUDGE: soft exit-0 nudge to run skill search before grepping. Not a block.
  17. GUARD 4 SKILL-EDIT-GUARD: blocks .skill.json direct Edit/Write. Fix: wkappbot skill edit <id> or skill contribute.
  18. GUARD 5 PACE-GUARD: blocks Sonnet Edit/Write when hogging. EXEMPT: memory/*.md and CLAUDE.md. Fix: delegate to Opus or Haiku.
