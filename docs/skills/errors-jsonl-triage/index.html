errors.jsonl Periodic Triage — Fix Frequent Errors Fast

Read .wkappbot/hq/logs/errors.jsonl, aggregate by command pattern, file suggest for patterns >=5 hits. Claude main duty at every gg cycle.

user/developer

Steps

  1. AFTER TRIAGE: clear resolved errors by rotating the file: Copy-Item .wkappbot\hq\logs\errors.jsonl .wkappbot\hq\logs\errors.jsonl.bak; ''>>.wkappbot\hq\logs\errors.jsonl (or wkappbot logcat --clear-errors if available).
  2. LOG FILE: .wkappbot/hq/logs/errors.jsonl -- each line is JSON with ts, cmd, exit, log fields. All non-zero exit wkappbot commands append here automatically.
  3. AGGREGATE (PowerShell): lines=Get-Content .wkappbot\hq\logs\errors.jsonl; ctr=@{}; foreach line: d=ConvertFrom-Json; cmd=d.cmd strip core exe prefix + normalize URLs/graps/big-nums; ctr[cmd]++. Sort by count desc, top 15.
  4. TRIAGE RULE: skip eye --replace-pid (normal restart). Patterns >=5 hits and not known-WAD = actionable. File wkappbot suggest for each actionable pattern.
  5. KNOWN WAD (skip): eye --replace-pid N (daemon restart). eye alone (daemon init). mcp wkappbot_cli (MCP probe -- check if MCP server needs restart if count high).
  6. ACTIONABLE PATTERNS: cdp tabs/navigate/open -- Chrome CDP port died; repair with wkappbot cdp open. win-click -- UIA target moved; check selector. cdp close/url/status -- stale grap after Chrome restart; run cdp open.
