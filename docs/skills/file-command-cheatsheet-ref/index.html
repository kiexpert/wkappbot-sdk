file cheatsheet reference

T3 gotchas for wkappbot file tools: grep starvation fallback, encoding safety, backup/undo.

user/developer
Part of: file-command-cheatsheet

Steps

  1. GREP STARVATION FALLBACK: when the built-in Grep tool fails with uv_spawn EUNKNOWN under resource starvation (Defender RAM storm), use wkappbot file grep (in-process, no subprocess spawn, gate-exempt). Running rg directly hits the same spawn starvation. Verified 2026-06-04 finding matches in a 1400-line file while built-in Grep failed.
  2. ENCODING: wkappbot file edit is UTF-8 and BOM and CRLF safe; after an edit a U+FFFD corruption triggers an auto Slack alert. Keep binary files (pdf, mp4, images) as-is, never text-convert.
  3. BACKUP UNDO: wkappbot file edit writes a .bak backup automatically; undo by restoring from that backup.
