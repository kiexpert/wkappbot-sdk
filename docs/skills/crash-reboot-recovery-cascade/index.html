  3. [WHY VS CODE WORKS BUT CONSOLE DOESNT] VS Code is a Win32 GUI app using TSF directly. Console apps use ConPTY/IMM32 path which requires ctfmon to be present at Windows Terminal startup time. After crash, ctfmon arrives too late for WT TSF registration window -> consoles broken, GUI apps fine.

[RECOVERY 1 - Korean IME + encoding] powershell -ExecutionPolicy Bypass -File C:\Users\kiexp\.codex\skills\recover-korean-console\scripts\recover-korean-console.ps1 -- restarts ctfmon+TextInputHost, sets UTF-8 InputEncoding/OutputEncoding, patches all live cmd.exe consoles via AttachConsole+SetConsoleCP API, registers ctfmon+chcp in registry.

[RECOVERY 2 - Windows Terminal IME still dead] Run: wkappbot skill read repair-korean-ime-running-wt-tsf-rebind -- injects msctf.dll into WT via CreateRemoteThread, calls TF_InvalidAssemblyListCacheIfExist, posts WM_INPUTLANGCHANGE to all CASCADIA_HOSTING_WINDOW_CLASS windows.
